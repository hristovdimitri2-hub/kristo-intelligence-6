Kristo Intelligence

Sentient Foundation — Open Source AGI Grant application · 20 November 2026 · grant track · ask: $25,000 · MIT licensed

A paid API for AI agents, and the measurement of what happens when an agent pays: whether the offer it saw is the offer that was signed, and whether the settlement it was told about is the settlement that exists.

What it is

Seven HTTP endpoints and seven MCP tools on Base, paid per call in USDC through x402 v2 — no API keys, no signup. Trading signals, whale flow, arbitrage radar, on-chain sales, seller verification. Prices $0.005–$0.050. Live at kristo-intelligence-api.onrender.com, source at github.com/hristovdimitri2-hub/kristo-intelligence-6.

The problem, measured from the seller's side

1. Settlement is non-terminal, and the boolean lies. The v2 spec names settlement_pending: the transaction was broadcast but confirmation could not be established. We read success: false as "payment failed", so we refused calls that had already been paid for. A facilitator operator measured ~19 settle failures across ~11.7k settlements, 9 of which had in fact settled.

2. The published offer is not the signed offer. The catalogue appends #toolName to a resource path, so /mcp#get_whale_flow is stored as /mcp#get_whale_flow#get_whale_flow. An unknown key inside accepts[0] is accepted and silently voids the row: eight settlements produced no listing. Removing two keys: listed in 45 seconds.

Both ends have the same shape: everything reports success, and the party that believes something happened is not the party that can check it.

Why this is the public good, not the product

  • Published conformance cases for settlement_pending — hash adoption, self-verification against the chain, matching on the error code and never on the message. The v2 spec names the state; it does not give a test.
  • A preview tool that walks a seller's paid routes, takes each 402, and diffs the declaration against the listing the catalogue intends to publish. First run against the live server: 7/7, no differences.
  • The honest-revenue split, published as a document rather than a headline: a stranger can check the demand behind the volume.

What we say against our own interest

  • The signal has no measured edge. 84 resolved signals, 52% hit rate, mean −0.56%. The published 1.2% is honest. Six of the seven endpoints sell facts; the seventh sells a forecast, and we say so.
  • The registry grades are mixed. x402register A 90.7; x402-list compliance A 14/14; x402lint B 84 with three fails — all three ours, all three now fixed; x402-trust marks /api/stats "avoid", which traces to our own key rotation and its own scoring method.
  • Two stars, no forks. The repository is not yet the reason anyone finds the project. The work is.
